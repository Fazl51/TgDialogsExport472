# TgDialogsExport472
Продвинутый телеграмм бот
Ну тут всё просто ,откройте файл Program.cs 
Укажите ваши данные в виде ID HASH NUMBER и API ключик от NEUROAPI 
После чего скомпелируйте проект 
Поздравляю у вас появился бот который умеет: 
1 Поддерживать диалог с собеседником (даже множество собеседников)
2 Создание различных личностей для общения 
3 Может скачивать и анализировать абсолютно все медиа из любых диалогов и каналов (в том числе и закрытых)
4 Может провести поведенчиский анализ собеседника 

Всё круто и работает на AI )
